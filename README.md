### 👨‍💻 About Me

I started my journey in IT in 2022 and have been actively exploring new technologies ever since. I am a **self-taught developer** — I learned programming entirely on my own, without courses or bootcamps. This helped me build strong problem-solving skills and the ability to learn independently through practice.

* 🔭 **Focus:** Python development, creating bots for **Telegram and Discord**, and backend for **web applications**.
* 🌱 **Currently learning:** Deep diving into databases (PostgreSQL), complex API integrations, and FastAPI/Flask architecture.
* 💡 **Approach:** I am comfortable navigating documentation independently and bringing projects from an idea to full deployment.
